## 张量（Tensor）—— PyTorch 的 NumPy

PyTorch 的 `tensor` 和 NumPy 的 `array` 几乎一样，只是 tensor 能在 GPU 上跑：

```python
import torch
import numpy as np

# 创建张量
x = torch.tensor([1.0, 2.0, 3.0])
y = torch.randn(3, 4)        # 3行4列，随机正态分布
z = torch.zeros(5, 2)         # 5行2列全零

# 和 NumPy 一样的运算
print(x + x)                  # [2, 4, 6]
print(x @ torch.tensor([4,5,6]))

# 放到 GPU 上
x_gpu = x.cuda()
# 或者 x_gpu = x.to("cuda")
```

## 自动求导 — PyTorch 真正的魔法

训练神经网络 = 找到让损失最小的参数。怎么找？需要计算梯度（偏导数）。

**PyTorch 帮你自动算。**

```python
# 一个简单的参数
w = torch.tensor([2.0], requires_grad=True)  # requires_grad = "帮我追踪这个值"

# 损失函数
loss = w ** 2                                 # 损失 = w²

# 自动算梯度
loss.backward()                               # 计算 d(loss)/dw
print(w.grad)                                 # 4.0（因为 d(w²)/dw = 2w = 4）
```

对于 G1 的训练，神经网络有几十万个参数。手算梯度是不可能的。`loss.backward()` 自动把所有参数的梯度都算完了。

## `nn.Module` — 搭网络像搭积木

```python
import torch.nn as nn

class MyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(4, 128),    # 全连接层：4 → 128
            nn.ReLU(),            # 激活函数（非线性的来源）
            nn.Linear(128, 128),  # 128 → 128
            nn.ReLU(),
            nn.Linear(128, 2),    # 128 → 2（最终输出）
        )
    
    def forward(self, x):
        return self.net(x)        # 输入 x，走过所有层，返回结果
```

### 每一层在干什么

| 层 | 干什么 | 通俗理解 |
|----|--------|----------|
| `nn.Linear(in, out)` | 矩阵乘法（in → out） | "把这 4 个数加权求和，得到 128 个数" |
| `nn.ReLU()` | 把负数变 0，正数不变 | "去掉不重要的信息" |
| `nn.Sequential(...)` | 把层串起来 | "流水线" |

## 训练三步走（你看 `train.py` 时会反复看到）

```python
# 1. 前向传播：拿预测结果
output = model(input_data)
loss = loss_function(output, target)

# 2. 反向传播：自动算梯度
optimizer.zero_grad()    # 清空上次的梯度
loss.backward()          # 自动求导

# 3. 更新参数
optimizer.step()         # 用梯度更新参数
```

actor_hidden_dims = [512, 256, 128]     # Actor 网络：输入 → 512 → 256 → 128 → 输出

## NumPy 和 PyTorch 怎么互转？

```python
# NumPy → Tensor
np_array = np.array([1.0, 2.0])
tensor = torch.from_numpy(np_array)

# Tensor → NumPy
np_back = tensor.numpy()
```

你在 notebook 里看到两种混用，它们基本上能自由转换。
