# 数据从哪来？ — 从 Q-Learning 到神经网络

> 你会在 notebook 里看到先用 Q 表写一个 RL 算法，然后换成神经网络。这不是"换一个库"——这是两种完全不同的思路。

---

## 问题：Q 表能管多少个状态？

网格世界里 4×4 = 16 个格子，Q 表 16×4 = 64 个数字。翻开表就能查。

G1 机器人呢？

```
网格世界的状态：              G1 的状态：
一格一格 → 16 个状态           29 个关节的角度 + 速度 + 姿态……
                             不是"16 个"，是连续空间——有无穷多种姿势
```

**Q 表装不下无穷多的状态。** 即使把每个关节的角度"四舍五入"到 0.1°，29 个关节的组合也超过宇宙原子总数。

---

## 解决：把"翻字典"换成"看图识物"

| | Q 表 | 神经网络 |
|---|---|---|
| **类比** | 📖 英汉词典——查"apple"→"苹果" | 📷 AI 识图——看一张照片→认出"猫" |
| **输入** | 离散编号（第 0 个格子） | 连续向量（29 个角度值） |
| **输出** | 查到的值 | 网络算出来的值 |
| **没见过的情况** | 查不到（表中没有） | 能猜个大概（因为见过类似的） |

---

## 神经网络到底在干什么？

用最简单的比喻：**自动猜规律的机器**。

给你一堆数据：

```
身高(cm)  体重(kg)
160       50
170       65
180       80
```

你一眼能看出：身高 ÷ 2 - 30 ≈ 体重。神经网络干的也是这事——从数据里**自动学出规律**。

只是它的规律比你上面的公式复杂得多——几百层、几百万个参数。但本质没变：

```
输入 (状态) → 神经网络 (一堆数学运算) → 输出 (预测每个动作的得分)
```

---

## 从 Q 表到 DQN 的变化

### Q-Learning

```python
# Q 表：手动建表，手动查表
Q = np.zeros((16, 4))
Q[state][action] += learning_rate * (reward - Q[state][action])
```

### DQN（Deep Q-Network）

```python
# 神经网络：自动算 Q 值
q_values = policy_net(state_tensor)
loss = (q_values[action] - target_q) ** 2
optimizer.zero_grad()
loss.backward()       # 自动求梯度
optimizer.step()      # 自动更新参数
```

**Q-Learning: "翻字典"**
**DQN: "看图识物"**

但两者的**核心思想完全一样**——用实际奖励来修正预估。

---

## 为什么用 PyTorch？

因为写一行 `loss.backward()` 就能自动算梯度。不用手算微积分。
