# DQN 实战 — 用神经网络玩 CartPole

> Q 表只能管 16 个格子。现在换连续的物理世界——一根杆子立在小车上，你要让它不倒。
>
> 用神经网络代替 Q 表，这就是 DQN。

---

## CartPole 是什么？

| 要素 | 对应 |
|------|------|
| **State** | 4 个连续值：小车位置、小车速度、杆角度、杆角速度 |
| **Action** | 2 个离散动作：推左 / 推右 |
| **Reward** | 杆子不倒每步 +1 分（最多 500 分） |
| **成功标准** | 连续 100 局平均 > 195 分 → 学会了 |

---

## 从 Q 表到神经网络

```
Q-Learning:                           DQN:
s → Q[s] → [0.5, -1.0, 0.8]         s → nn(s) → [0.5, -1.0, 0.8]
     ↑ 翻字典                               ↑ 神经网络算
```

**网络结构**：

```
输入层(4) → 全连接(128) → ReLU → 全连接(128) → ReLU → 全连接(2)
  ↑                                                        ↑
 小车位置、速度、杆角度、角速度                      推左的Q值、推右的Q值
```

## 训练代码核心流程

```python
for episode in range(200):
    state = env.reset()
    while True:
        # 1. 选动作（ε-greedy：90%选最佳，10%随机探索）
        if random() < epsilon:
            action = random.randint(0, 1)
        else:
            action = argmax(policy_net(state))
        
        # 2. 执行动作，存经验
        next_state, reward, done = env.step(action)
        buffer.push(state, action, reward, next_state, done)
        
        # 3. 从经验池抽样学习
        batch = buffer.sample(64)
        loss = MSELoss(policy_net(batch), target_q)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        if done: break
```

## 两个关键技巧

### 1. Replay Buffer（经验回放）

**问题**：每步的经验前后相关（第 1 步和第 2 步很像），连续学习会导致网络"只学会最近的情况"。

**解决**：把所有经验丢到一个大池子里，训练时随机抽一批。一个经验能反复学，还能打破时间相关性。

### 2. Target Network（目标网络）

**问题**：Q 网络追自己的尾巴——用自己的输出当目标，训练不稳定。

**解决**：维护一个目标网络的**冻结副本**，每 100 步同步一次。训练时不追自己，追一个稳定目标。

## 从 CartPole 到 G1

| | CartPole DQN | G1 PPO |
|---|---|---|
| 状态维度 | 4 | ~200 |
| 动作维度 | 2（离散） | 29（连续） |
| 算法 | DQN | PPO |

**但核心逻辑一模一样**：看状态 → 做动作 → 得奖励 → 更新网络。

PPO 在处理连续动作时比 DQN 更稳定，所以 G1 训练用它。但从思想层面，你已经懂了。
