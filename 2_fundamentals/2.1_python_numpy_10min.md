## Python 是什么？

Python 是**解释型语言**——写完代码不需要"编译"这一步。你写了就能跑：

```python
# hello.py
print("Hello!")
```

```bash
python3 hello.py    # 直接跑，不需要先 gcc 编译
```

对比 C 语言（编译型）：
```c
// hello.c → gcc hello.c → ./a.out   需要先编译再运行
```

**解释型 = 边读边执行**。对你来说意味着：**改了代码立刻生效，不需要等编译**。

## 你天天会看到的 Python 语法

### 1. 变量和类型

```python
name = "G1"           # 字符串
age = 5               # 整数
height = 1.27         # 小数（浮点数）
is_walking = True     # 布尔值（True/False）
```

Python 不需要声明类型——写了 `5` 它就是整数。

### 2. 列表和字典

```python
# 列表（list）—— 有序的一串东西
joints = ["hip", "knee", "ankle"]
print(joints[0])        # 输出 "hip"（从 0 开始计数！）
print(len(joints))      # 输出 3

# 字典（dict）—— 键值对，查表用
q_table = {"蹲下": 0.5, "趴下": -1.0, "不理": 0.0}
print(q_table["蹲下"])   # 输出 0.5
```

### 3. 循环和条件

```python
# for 循环
for i in range(10):        # 0, 1, 2, ..., 9
    print(i)

# if/else
reward = 10
if reward > 0:
    print("好！")           # 奖励为正走这个
else:
    print("差！")           # 奖励为负走这个
```

### 4. 函数

```python
def add(a, b):            # 定义一个函数
    return a + b

result = add(3, 5)        # 调用
print(result)             # 输出 8
```

### 5. `import` —— 用别人写好的代码

```python
import numpy as np        # 导入 NumPy，起个别名叫 np
import torch              # 导入 PyTorch

x = np.array([1,2,3])     # 用 NumPy 建的数组
print(x)
```

## NumPy — 所有 RL 数据的基本单位

NumPy 是 Python 的数学计算库。RL 里的状态、动作、奖励……全是 NumPy 数组。

### 创建数组

```python
import numpy as np

# 一维数组
x = np.array([1, 2, 3, 4])

# 二维数组（矩阵）
A = np.array([[1, 2], [3, 4]])

# 全零数组
zeros = np.zeros((3, 4))   # 3行4列的全零矩阵

# 随机数组
rand = np.random.random((2, 3))  # 2行3列的随机矩阵
```

### `.shape` 属性 — 看数组的结构

```python
print(zeros.shape)         # (3, 4) — 3行4列
```

### NumPy 的核心优势：向量化运算

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)               # [5, 7, 9]   不用写循环！
print(a * 2)               # [2, 4, 6]   每个元素都乘2
print(a @ b)               # 32         内积！(1×4 + 2×5 + 3×6)
```

**不需要写循环**。NumPy 把循环推到了 C 语言层面（比 Python for 循环快 500-1000 倍）。

### `argmax` — 找最大值的索引

```python
scores = np.array([0.5, -1.0, 0.8, -2.0])
best = np.argmax(scores)    # 输出 2（第2个元素是最大的 0.8）
```

在 RL 里，`argmax(Q[s])` = 在状态 s 里选 Q 值最高的那个动作。
