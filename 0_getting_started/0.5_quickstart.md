# 快速开始 — 三条命令看到 G1 机器人

> 你已经知道终端怎么用、Git 是什么、你的电脑能跑。现在三步看到效果。

---

## 前提检查

在终端里跑这一条：

```bash
nvidia-smi && sudo docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi
# 两条都显示你的 GPU → ✅ 可以继续
# 有任何报错 → 去 1_environment/ 从头配
```

---

## 第 1 步：拿到菜谱（克隆项目）

```bash
# HTTPS 方式（不用配 SSH key）
git clone https://github.com/GXMZU-AITECC/unitree-g1-demo.git ~/projects/g1-rl

# 或者 SSH（需要先配 SSH key，看 1.5_Isaac_Sim）
git clone git@github.com:GXMZU-AITECC/unitree-g1-demo.git ~/projects/g1-rl

cd ~/projects/g1-rl
```

> 💡 `~/projects/g1-rl` 只是个例子，仓库放哪儿都行——脚本会自己找到自己在哪。
> 后面的命令都在仓库根目录里执行。

---

## 第 2 步：拉取依赖

```bash
# 2a. 登录 NVIDIA NGC（需要注册：https://catalog.ngc.nvidia.com/ → API Key）
sudo docker login nvcr.io
# 用户名填: $oauthtoken（字面量，带美元符号）
# 密码填: 你的 NGC API Key

# 2b. 拉取 Isaac Sim 镜像（~23GB，首次 20-40 分钟）
sudo docker pull nvcr.io/nvidia/isaac-sim:5.1.0

# 2c. 克隆 G1 代码仓库
mkdir -p sim
cd sim
git clone https://github.com/unitreerobotics/unitree_rl_lab.git
git clone https://github.com/unitreerobotics/unitree_ros.git
git clone https://github.com/isaac-sim/IsaacLab.git
# 走到 5.4「Sim2Sim 验证」时才需要第 4 个仓库，现在顺手一起拉，省得到时候现装：
git clone https://github.com/unitreerobotics/unitree_mujoco.git
cd ..
```

> 💡 如果你在国内，`git clone` 和 `docker pull` 可能会超时——先去 [1.6_代理配置](../1_environment/1.6_proxy_setup.md) 配代理。

---

## 第 3 步：安装依赖 & 开始训练

```bash
# 3a. 安装 RL 训练库（只做一次）
bash scripts/start.sh install

# 3b. 开始训练！
bash scripts/start.sh train
```

终端里会出现：

```
=== G1 RL Training (headless) ===
Task: Unitree-G1-29dof-Velocity  Envs: 4  Iter: 20000

                          Learning iteration 1/20000
                       Steps per second: 112
                            Mean reward: -4.35
                    Mean episode length: 40.18
```

**这就代表训练开始了！** 

- `Mean reward: -4.35` → 刚开始是负的，正常（机器人还在乱动）
- `bad_orientation: 1.0` → 每次都摔倒，正常（还没学会走路）
- 500-1000 轮之后开始站立，5000 轮后开始走路

## 一键菜单

```bash
bash scripts/start.sh
# 弹出交互式菜单：
# 1 → visualize  3D可视化
# 2 → train      无头训练（最快）
# 3 → train-gui  带3D画面训练
# 4 → play       回放模型
# 5 → shell      进入容器
# 6 → install    安装依赖（首次必做）
```

## 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `docker login nvcr.io` 报 unauthorized | 用户名填错了 | 填 `$oauthtoken`（字面量），不是你的邮箱 |
| `docker pull` 超时 | 墙 | → [1.6_代理配置](../1_environment/1.6_proxy_setup.md) |
| `ModuleNotFoundError: gymnasium` | 还没装依赖 | `bash scripts/start.sh install` |
| 3D 窗口一片黑 | 容器没以 root 运行 | `scripts/start.sh` 已配好 `--user 0:0`。手动跑要加这个 |
| `nvidia-smi` 显示 595 驱动 | 驱动版本不兼容 | → [1.4_GPU驱动](../1_environment/1.4_nvidia_driver_gpu.md) |
