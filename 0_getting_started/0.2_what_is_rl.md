# 什么是强化学习？—— 5 分钟看懂

> 不需要任何数学背景。你只需要知道"训练一只狗"是怎么回事。

---

## 训狗的类比

想象你养了一只狗，想教它"坐下"。

```
你喊 "坐下"  →  狗犹豫了一下，歪着头看你  →  没有奖励
你喊 "坐下"  →  狗蹲下了                  →  给一块肉干 🦴
你喊 "坐下"  →  狗立刻蹲下                 →  给两块肉干 🦴🦴
```

反复几十次之后，狗学会了：**听到"坐下" → 立刻蹲下 → 能得到肉干**。

这就是强化学习的全部思想。只有三个要素：

| 训狗 | 强化学习 | 什么意思 |
|------|----------|----------|
| 🗣️ 你的口令 "坐下" | **State（状态）** | 此刻发生了什么 |
| 🐕 狗的动作（蹲下/趴下/不理你） | **Action（动作）** | 能做什么选择 |
| 🦴 肉干（给/不给/多给） | **Reward（奖励）** | 做对了给奖，做错了扣分 |

## 强化学习的核心循环

```
          ┌──────────────────────────────────┐
          │                                    │
          ▼                                    │
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │  观察状态  │ ──▶ │  做出动作  │ ──▶ │  得到奖励  │
    │  State   │     │  Action  │     │  Reward  │
    └──────────┘     └──────────┘     └──────────┘
          ▲                                    │
          └────────────────────────────────────┘
                 （下一次状态变成新的）
```

**就是这么简单**：agent（机器狗/机器人）看环境 → 做动作 → 得到反馈 → 调整自己下次做得更好。

## 换成 G1 机器人的例子

把"训狗"换成"训练 G1 学会走路"：

| 要素 | 对应什么 |
|------|----------|
| **State 状态** | G1 此刻的"姿势"：每个关节的角度、身体倾斜多少、脚踩在哪里 |
| **Action 动作** | G1 能做的"动作"：髋关节转多少度、膝关节弯多少、脚踝怎么扭 |
| **Reward 奖励** | **+1 分**：走得快、走得稳、身体不歪； **-1 分**：摔倒、脚步太乱、走偏方向 |
| **Policy 策略** | "看到这个姿势 → 关节这样动"。就是 G1 的"大脑"，是一个神经网络 |

## 为什么叫"强化"学习？

因为学习的过程就是**不断强化正确的行为**。

```
狗蹲下了 → 给肉干 → 强化 "听到'坐下'就蹲下" 这条规则
          （下次更可能这样做）

G1 迈了一步没摔倒 → 奖励 +1 → 强化 "这样迈步安全" 这个策略
                    （下次更可能这样迈步）
```

**反过来**：狗扑人 → 不给奖励 → "扑人没好处"被弱化  
G1 膝盖弯太猛摔倒了 → 扣分 → "弯这么猛危险"被弱化

**强化**两个字，就是"把能拿奖励的行为变得更强"。

## 你不需要懂的（现在）

当你开始动手之后会看到这些词。下面每个词用一句话解释，**现在不用背，碰到了回来看一眼就行**：

| 术语 | 一句话 |
|------|--------|
| Episode | 一个完整的"回合"。狗训练一次 = 从"坐下"到"吃到肉干"，G1 一个 Episode = 从站好到摔倒或走满 20 秒 |
| Policy（策略） | 机器人做决策的"大脑"——看到什么状态，就做出什么动作 |
| PPO | 目前最流行的一种强化学习算法。你不需要理解它的公式，就当它是"训练策略大脑的标准方法" |
| Reward 函数 | 一套打分规则——设计"做什么事给多少分"。是强化学习里**最难也最重要**的部分 |
| 探索 vs 利用 | 狗"偶尔试试新动作"（探索） vs "只做确定有肉干的动作"（利用）。太保守学不到新东西，太浪会一直失败 |
| 神经网络 | 一个模仿人脑神经元的结构，输入"状态"输出"动作"。你当它是一个自动调参的黑盒子就行 |
| 训练迭代（Iteration） | 收集数据 → 更新策略，算一轮。500 轮后机器人开始站立，5000 轮后开始走路 |
