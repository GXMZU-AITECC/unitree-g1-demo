# Isaac Sim + G1 仓库 — 拉取仿真环境和机器人模型

> 这是环境安装的第 3 步：拉取 Isaac Sim 镜像，克隆 G1 机器人的代码仓库。
>
> 预计时间：~30 分钟（主要看网速）

---

## 这一节解决什么问题？

现在 Docker 和 GPU 驱动都 OK 了，该把仿真"引擎"和 G1 的模型文件拉下来了。

- **Isaac Sim**：NVIDIA 的机器人仿真引擎，提供物理运算和 3D 渲染。通过 Docker 镜像分发，~23GB。
- **G1 仓库**：Unitree 官方提供的 RL 训练代码（`unitree_rl_lab`）和 G1 的 3D 模型文件（`unitree_ros` 里的 URDF）。

---

## 第 1 步：注册 NVIDIA NGC 账户

NGC 是 NVIDIA 的 GPU 云服务，Isaac Sim Docker 镜像托管在上面。

1. 打开 https://catalog.ngc.nvidia.com/
2. 注册/登录 NVIDIA 账号
3. 右上角头像 → **Setup** → **Get API Key**
4. 生成 API Key，**复制保存**（只显示一次！）

登录 Docker：

```bash
sudo docker login nvcr.io
# 用户名: $oauthtoken        ← 注意！字面量，带美元符号
# 密码: <刚才复制的 API Key>
```

---

## 第 2 步：拉取 Isaac Sim 镜像

```bash
sudo docker pull nvcr.io/nvidia/isaac-sim:5.1.0
```

> ⏱️ 镜像约 23GB，首次下载 20-40 分钟。可以在另一个终端跑 `watch nvidia-smi` 看着。

拉完后验证：

```bash
sudo docker images | grep isaac-sim
# 应该看到 5.1.0 版本的镜像，约 22.9GB
```

---

## 第 3 步：克隆 G1 机器人仓库

```bash
mkdir -p ~/projects/g1-rl/sim
cd ~/projects/g1-rl/sim

# Unitree 官方 RL 训练库
git clone https://github.com/unitreerobotics/unitree_rl_lab.git

# Unitree 机器人模型库（G1 的 URDF 文件在这）
git clone https://github.com/unitreerobotics/unitree_ros.git

cd ..
```

> 这两个仓库加起来约 500MB，在 `sim/` 目录下。注意 `sim/` 在 `.gitignore` 里，不会提交到你的 GitHub 仓库——每台机器自行克隆。

看看 G1 的模型文件：

```bash
ls sim/unitree_ros/robots/g1_description/
# 应该看到 g1_29dof_rev_1_0.urdf 等文件 — 这些是 G1 的 3D 描述文件
```

---

## 第 4 步：克隆 IsaacLab（可选，但推荐）

IsaacLab 是 Isaac Sim 之上的 RL 框架，提供了 PPO 训练循环和 G1 环境注册。我们项目引用了它的代码：

```bash
cd ~/projects/g1-rl/sim
git clone https://github.com/isaac-sim/IsaacLab.git
cd ..
```

> 如果你跳过这一步，项目里的某些兼容性修复（如 `utils.py` 的 `hasattr` 守卫）就没法用了。

---

## 第 5 步：检查镜像内的 Isaac Sim 环境

```bash
# 进入镜像的交互式 Shell
sudo docker run --rm --gpus all --user 0:0 \
  --entrypoint bash -it \
  nvcr.io/nvidia/isaac-sim:5.1.0

# 在容器内：
ls /isaac-sim/                    # Isaac Sim 安装位置
/isaac-sim/kit/python/bin/python3 --version  # Python 3.10
nvidia-smi                        # GPU 直通
exit                              # 退出容器
```

```

├── 1_environment/           # 安装教程（你正在看的）

├── 4_advanced/              # 高级拓展

```

## 🆘 常见问题

### `docker pull` 超时 / 卡住

网络问题。需要配代理 → [1.6_代理配置](1.6_proxy_setup.md)

### `git clone` GitHub 仓库失败 (GnuTLS handshake failed)

改 SSH 协议：
```bash
# 1. 生成 SSH key
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github

# 2. 把 ~/.ssh/id_ed25519_github.pub 的内容添加到 https://github.com/settings/keys

# 3. 用 SSH 协议克隆
git clone git@github.com:unitreerobotics/unitree_rl_lab.git
git clone git@github.com:unitreerobotics/unitree_ros.git
git clone git@github.com:isaac-sim/IsaacLab.git
```

详细代理配置 → [1.6_代理配置](1.6_proxy_setup.md)
