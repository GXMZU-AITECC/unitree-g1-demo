# 三种"装软件"的方式 — apt、pip、Docker pull

> 你在教程里看到 `sudo apt install`、`pip install`、`docker pull`，它们都是"装东西"，但管的范围不一样。
>
> 这章用一句话解释每种方式。

---

## 一句话定义

| 命令 | 管什么的 | 在这个项目里你用它装了什么 |
|------|----------|--------------------------|
| `apt install` | **操作系统级**的软件 | Docker、Git、gcc 编译器 |
| `pip install` | **Python 包** | gymnasium、rsl-rl-lib、tensorboard |
| `docker pull` | **整个环境打包好的镜像** | Isaac Sim（23GB，包含 Ubuntu + Python + CUDA + 渲染引擎） |

---

## `apt` — 装系统级的软件

```bash
sudo apt update                  # 先刷新"软件菜单"
sudo apt install docker.io       # 按菜单点菜
```

**管什么**：不是 Python 的软件——Docker、Git、gcc。装在 `/usr/bin/` 下，整个系统都能用。

**为什么需要 `sudo`**：装系统级软件要管理员权限。

---

## `pip` — 装 Python 包

```bash
pip install gymnasium            # 装 gymnasium（RL 环境库）
pip install tensorboard          # 装 TensorBoard
```

**管什么**：纯 Python 的库。装在你当前 Python 环境的 `site-packages/` 目录下。

---

## `docker pull` — 下载打包好的完整环境

```bash
sudo docker pull nvcr.io/nvidia/isaac-sim:5.1.0
```

**管什么**：**整个环境**——不是"装一个包"，是"下载一个已经配好的迷你 Ubuntu 24.04"。镜像里 Ubuntu + Python 3.10 + Isaac Sim + CUDA 全有了。

---

## Conda 呢？

你在这个项目里**基本用不到 conda**。

```
你的训练是在哪跑的：
  ❌ 不是 conda env_isaaclab 里
  ✅ 是 Docker 容器里的 /isaac-sim/kit/python/bin/python3
```

训练的全流程——`train.py`、`play.py`、物理仿真——全在 Docker 容器内执行。容器自带 Python 3.10，不需要宿主机的 conda。

conda 只在一个场景有用：你在宿主机上看 TensorBoard 时，需要 pip 安装 tensorboard。但那用系统的 pip 就行，不一定需要 conda。

**结论：conda 在 AGENTS.md 里出现是因为项目初始化时建了它，但你日常训练用不到它。**

---

## 总结：你实际用到的只有两种

| 你要... | 用什么 | 例子 |
|---------|--------|------|
| 装 Docker、Git | `apt` | `sudo apt install docker.io` |
| 在**容器里**装 Python 包 | `pip`（容器内执行） | `bash scripts/start.sh install` |
| 拉 Isaac Sim 镜像 | `docker pull` | `sudo docker pull nvcr.io/nvidia/isaac-sim:5.1.0` |
