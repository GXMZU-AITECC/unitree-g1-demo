# 代理配置 — 国内网络环境专用

> 如果你在中国大陆，GitHub、Docker Hub、NVIDIA NGC 基本都直连不上。这一节教你配代理。
>
> 如果你在海外，跳过这一节。

---

## 你需要一个代理工具

以 **Clash Verge** 为例（最常用的方案）：

1. 下载 `.deb` 包：https://github.com/clash-verge-rev/clash-verge-rev/releases
2. 安装：`sudo apt install ./Clash.Verge_*_amd64.deb`
3. 启动 Clash Verge，导入你的订阅链接
4. 开启 **TUN 模式**（让整个系统的流量都走代理）

验证代理在运行：
```bash
ss -tlnp | grep mihomo
# 应该看到 127.0.0.1:7897 在监听
```

> ⚠️ TUN 模式只代理系统流量。**Docker daemon 需要单独配置**，下面会说。

---

## 第 1 步：让 Docker Daemon 走代理

Docker 拉镜像时用的是 Docker daemon（后台进程），不走系统代理。需要单独配置：

```bash
sudo mkdir -p /etc/systemd/system/docker.service.d

sudo tee /etc/systemd/system/docker.service.d/http-proxy.conf << 'EOF'
[Service]
Environment="HTTP_PROXY=http://127.0.0.1:7897"
Environment="HTTPS_PROXY=http://127.0.0.1:7897"
Environment="NO_PROXY=localhost,127.0.0.1,::1"
EOF

# 重启 Docker daemon 让配置生效
sudo systemctl daemon-reload
sudo systemctl restart docker
```

验证：
```bash
sudo systemctl show docker | grep HTTP_PROXY
# 应该看到你设的代理地址
```

---

## 第 2 步：让 Git 走 SSH 代理

Git over HTTPS 在国内经过代理时经常报 `GnuTLS handshake failed`。改用 SSH 协议：

```bash
# 1. 生成 SSH 密钥
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github

# 2. 把公钥添加到 GitHub
# 复制内容：
cat ~/.ssh/id_ed25519_github.pub
# 打开 https://github.com/settings/keys → New SSH Key → 粘贴 → Save

# 3. 配置 SSH 走代理
cat >> ~/.ssh/config << 'EOF'
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_github
    ProxyCommand nc -X connect -x 127.0.0.1:7897 %h %p
    StrictHostKeyChecking accept-new
EOF

# 4. 测试
ssh -T git@github.com
# 应该看到 "Hi <你的用户名>! You've successfully authenticated..."
```

## Docker 镜像加速器（备选方案）

如果代理不方便，可以试试国内 Docker 镜像加速器。但注意：**加速器不完全可靠，很多已被屏蔽。**

编辑 `/etc/docker/daemon.json`（如果不存在则创建）：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerhub.timeweb.cloud"
  ]
}
```

```bash
sudo systemctl restart docker
```

---

## TUN 模式 vs Docker 代理

这两者不会冲突：

| 模式 | 作用范围 | 用途 |
|------|---------|------|
| TUN 模式 | 系统应用（浏览器、wget、pip） | 下载Python包、浏览网页 |
| Docker daemon 代理 | 拉取 Docker 镜像（`docker pull`） | 拉 Isaac Sim 镜像 |
| Git SSH + ProxyCommand | Git 克隆 | 克隆 GitHub 仓库 |
