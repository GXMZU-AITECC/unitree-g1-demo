# VS Code 开发容器 — 一键环境，零配置

> 如果你用 VS Code，这是**最简单的入门方式**。
>
> 安装 VS Code + Docker 后，单击一个按钮就能进入配置好的 Isaac Sim RL 训练环境。

---

## 这是什么？

VS Code 的"开发容器"(Dev Container) 功能：**在你的 Docker 容器里开发，就好像容器是你的操作系统一样。**

```
你的 VS Code（Windows/Linux/Mac）
    │
    │  "在容器中重新打开" ← 点一下
    │
    ▼
┌─────────────────────────────┐
│ Docker 容器                   │
│ ├─ Ubuntu 24.04              │
│ ├─ Isaac Sim 5.1.0           │  ← VS Code 把终端、调试器、文件浏览器都连到这里
│ ├─ Python 3.10               │
│ ├─ RSL-RL + Gymnasium        │
│ └─ G1 所有代码               │
└─────────────────────────────┘
```

---

## 第 1 步：安装必要工具

```bash
# 1. 安装 VS Code
# 从 https://code.visualstudio.com/ 下载 .deb 包
sudo apt install ./code_*.deb

# 2. 安装 VS Code 扩展
# 打开 VS Code → 左侧扩展面板 → 搜索 "Dev Containers" → 安装
# 扩展 ID: ms-vscode-remote.remote-containers

# 3. 确认 Docker 已安装
sudo docker run --rm hello-world
```

---

## 第 2 步：打开项目

```bash
cd ~/projects/g1-rl
code .
# ↑ 在 VS Code 中打开当前目录
```

---

## 第 3 步：一键进入容器

VS Code 打开项目后会检测到 `.devcontainer/` 目录，右下角弹出提示：

```
→ 文件夹包含开发容器配置文件。是否在容器中重新打开？
   [在容器中重新打开]
```

**单击"在容器中重新打开"**。

第一次构建需要 20-40 分钟（拉取 Isaac Sim 镜像 + 安装依赖）。之后再次打开只需要几秒。

---

## 第 4 步：在容器里开发

进入容器后，VS Code 底栏左侧会显示 `Dev Container: G1 RL Training`。

```bash
# 在 VS Code 的终端里（它自动连到了容器内部）：
cd /workspace

# 安装训练依赖
bash scripts/start.sh install

# 开始训练
bash scripts/start.sh train-gui
```

**你可以像在本地一样**：
- 编辑 Python 代码（有语法高亮、自动补全）
- 运行训练脚本（GPU 直通容器）
- 查看训练日志（TensorBoard 在容器内运行，浏览器在宿主机打开）
- Git 提交、推送（VS Code 的 Git 面板直接操作宿主机仓库）

---

## devcontainer.json 解读

`.devcontainer/devcontainer.json`（配置你上面看到的）：

```json
{
  "name": "G1 RL Training",
  "build": {
    "dockerfile": "Dockerfile"     // 构建容器用什么 Dockerfile
  },
  "runArgs": [
    "--gpus", "all",               // 让容器访问 GPU
    "--user", "0:0",               // root 权限（Isaac Sim 需要）
    "--network=host"               // 宿主机网络
  ],
  "workspaceMount": "source=${localWorkspaceFolder},target=/workspace,type=bind",
  "workspaceFolder": "/workspace", // 容器内的项目根目录

  // VS Code 自动安装这些扩展到容器里
  "customizations": {
    "vscode": {
      "extensions": [
        "ms-python.python",        // Python 支持
        "ms-toolsai.jupyter",      // Jupyter Notebook 支持
        "ms-azuretools.vscode-docker"  // Docker 语法高亮
      ]
    }
  }
}
```

## 常见问题

### Q: 弹出的是"重新打开"还是"重新构建"？
A: 第一次选"在容器中重新打开"，会自动构建。之后改了 Dockerfile 才需要重建（VS Code 会提示）。

### Q: Dev Container 能跑 GUI 吗？
A: Isaac Sim 的 GUI 需要 X11 转发。在 `devcontainer.json` 的 `runArgs` 里添加：
```json
"runArgs": [
  ...,
  "--env", "DISPLAY=${localEnv:DISPLAY}",
  "--volume", "/tmp/.X11-unix:/tmp/.X11-unix"
]
```

### Q: 和直接用 `bash scripts/start.sh` 有什么区别？
A: `start.sh` 是直接跑 Docker 容器执行训练脚本。Dev Container 是**在容器里打开完整的开发环境**——你可以改代码、调试、跑 notebook，不只是执行训练。

### Q: Windows 上能用吗？
A: 可以！但 Isaac Sim 的 GUI 在 Windows 上需要 X Server（如 VcXsrv）。headless 训练完全没问题。
