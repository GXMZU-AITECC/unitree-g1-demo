# 5.10 附加：Mimic 动作模仿控制器

> 除了 "遥控走路" 的速度跟踪模式，G1 还有一个 Mimic 模式——让机器人**自动播放一段动作**，比如跳舞。

---

## Mimic 是什么？

Mimic 控制器用 RL 策略来**跟踪一段预录的动作轨迹**（关节角度随时间变化的序列）。

它和 Velocity 控制器的区别：

| | Velocity | Mimic |
|---|---|---|
| **输入** | 摇杆速度指令 | 目标关节角度（从 CSV 读） |
| **输出** | 关节位置偏移量 | 关节位置偏移量（结构一样） |
| **策略目标** | 按指令速度走路 | 精确跟踪动作轨迹 |
| **控制方式** | 手动（摇杆） | 自动（播放） |
| **时长** | 无限（直到切换状态） | 有限（motion_file 的长度） |

---

## 为什么默认禁用了？

Mimic 需要两个额外的文件：
1. **Mimic ONNX 模型**（`policy.onnx`）——一个专为动作跟踪训练的神经网络
2. **动作轨迹文件**（`.csv`）——包含每一帧的每个关节的目标角度

这两个都不在 Velocity 训练中产生。你必须用专门的 Mimic 训练流程来训练对应的模型。

---

## 如何启用 Mimic

如果你已经有了 Mimic 训练的模型和 CSV 文件，在 `deploy/g1_29dof/config/config.yaml` 中取消注释：

```yaml
FSM:
  _:
    # ... Passive, FixStand, Velocity ...
    Mimic_Dance_102:    # ← 删除开头的 #
      id: 101
      type: Mimic
    Mimic_Gangnam_Style: # ← 删除开头的 #
      id: 102
      type: Mimic

  Velocity:
    transitions:
      Passive: LT + B.on_pressed
      Mimic_Dance_102: LT(2s) + down.on_pressed      # ← 取消注释
      Mimic_Gangnam_Style: LT(2s) + left.on_pressed  # ← 取消注释
```

然后把 Mimic 训练的 `exported/policy.onnx` + `params/deploy.yaml` + CSV 动捕文件放进对应的 `config/policy/mimic/<name>/` 目录。

## Mimic 源码关键差异

在 `State_Mimic.cpp` 中，与 `State_RLBase.cpp` 的主要区别：

```cpp
// State_Mimic 有一个独立的推理线程
std::thread policy_thread_;

// 它预加载整个动作轨迹
std::vector<std::vector<float>> motion_frames_;  // 从 CSV 读

// 用线性插值器做帧间平滑
LinearInterpolator interpolator_;

// 推理线程的实现：
void policy_thread_func() {
    while (running) {
        auto t0 = std::chrono::steady_clock::now();
        
        env->robot->update();
        env->compute_observations();
        // 观察中包含当前目标帧的关节位置（来自 motion_frames_）
        env->alg->act(obs);
        env->process_actions();
        
        auto t1 = std::chrono::steady_clock::now();
        auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(t1 - t0);
        // 睡眠到下一个控制周期 (0.02s)
        std::this_thread::sleep_for(std::chrono::milliseconds(20) - elapsed);
    }
}
```

**关键**：Mimic 在每个推理步中把 "当前应该在哪一帧" 的目标关节角度作为观察输入的一部分。策略学习的是 "当前状态 vs. 目标状态 → 应该使多大的力来缩小差距"。

## 不需要自己训练 Mimic

Mimic 训练需要动捕数据（BVH 文件 → CSV），这是一个不同的训练流程。本教程项目聚焦于 **Velocity（速度跟踪）**。

如果你想探索 Mimic，参考 unitree_rl_lab 的 Mimic 训练文档。
