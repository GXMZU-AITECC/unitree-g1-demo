# 5.7 在机器人上运行

> 编译器产出了 `g1_ctrl`。现在——让机器人动起来。
>
> ⚠️ **重要**：这是给真实 G1 机器人通电的实际操作。机器人摔倒可能损坏硬件。**第一次跑一定要有人在旁边扶着。**

---

## 类比：开车上路之前

你会先检查：
- 车周围有没有人
- 手刹有没有拉
- 安全带有没有系

跑机器人也是一样。先检查，再启动。

---

## 安全检查清单

在运行之前，**逐条确认**：

- [ ] 机器人周围有 ≥2m×2m 的空旷平整地面
- [ ] 有**两个人**在场：一人操作手柄，一人扶着机器人
- [ ] 机器人电量 > 50%
- [ ] 紧急停止按钮已连接且能用
- [ ] 没有线缆悬空会被运动中的关节夹到
- [ ] 你已经知道怎么紧急停车：**L2 + B**（用手柄按这两个键）

---

## 手柄：哪个键在哪儿？

G1 配套的手柄一般是一个类似 Xbox 手柄的摇杆。

```
        ┌──────────────────────────┐
        │         屏幕（可选）       │
        │                          │
        │  LB          RB          │  ← 上排按钮（食指位置）
        │                          │
        │  LT          RT          │  ← 扳机（食指位置，可压住不放）
        │                          │
        │    ↑                     │
        │  ←   →    左摇杆          │  ← 主要控制：前进后退左右转
        │    ↓                     │
        │                          │
        │    ▲                     │
        │  ◄   ►    右摇杆          │  ← 横向移动
        │    ▼                     │
        │                          │
        │  X     Y     A     B     │  ← 右侧按钮（拇指位置）
        └──────────────────────────┘
```

**本节用到的按键**：
- **L2** = 左手食指那里的扳机（可以压住不放）
- **B** = 右侧按钮
- **↑（方向键上）** = 左手拇指那里
- **R1** = 右手食指上方的按钮
- **X** = 右侧按钮（左侧那个）

> 不用记。下面每一步都会告诉你怎么按。

## 运行！

### 1. 先把机器人放好

- 机器人**平躺在地上**（不要扶着让它站）
- 这样它启动时处于被动（Passive）态——关节是软的，不会突然动

### 2. 启动控制器

```bash
# 确认你在 build/ 目录下
cd ~/g1-rl-deploy/g1_29dof/build

# 启动
./g1_ctrl --network eth0
```

你会看到：

```
 --- Unitree Robotics ---
     G1-29dof Controller
Waiting for connection to robot...
Connected to robot.
Policy directory: .../policy/velocity/v0
Press [L2 + Up] to enter FixStand mode.
And then press [R1 + X] to start controlling the robot.
```

最后的提示就是在告诉你按什么键进入下一步。

> 如果卡在 `Waiting for connection...` 很久不出来，说明网络接口不对。试试 `./g1_ctrl --network wlan0` 或其他网卡名（用 `ifconfig` 看有哪些网卡）。

### 3. 站起来 → 走路

```
第 1 步：L2 + ↑         机器人从地上站起来
                         → 关节绷紧，站姿稳定
                         等 2-3 秒让它站稳

第 2 步：R1 + X          神经网络模型开始接管
                         → 机器人开始小步行走！

第 3 步：左摇杆 ↑        机器人向前走
         左摇杆 ↓        机器人后退
         左摇杆 ←        左转
         左摇杆 →        右转
         右摇杆 ←→       横向移动（螃蟹步）

紧急停止：L2 + B         立即回到 Passive
                         → 所有关节卸力，机器人软掉倒地
```

> 🛑 **L2 + B 就是"急停按钮"**。任何时候觉得不对劲，按住这两个键。机器人会立刻没力气，自然倒地。让它倒——不要试图用手接住 30kg 的机器人。

### 4. 第一次走路的建议

- **先小幅度推左摇杆**——让机器人慢慢走
- **观察步态**——走得平稳吗？有没有拖脚？有没有左右晃？
- **慢慢加快**——逐渐把摇杆推到底
- **测试转向**——轻轻推左摇杆左右，看机器人转不转
- **别急着退**——后退比前进难。先练好前进再试后退

## 正常退出

```bash
# 方法 1：直接按 Ctrl+C（程序会自动先切到 Passive 再退出）

# 方法 2：先按 L2+B（回到 Passive），再按 Ctrl+C
```

退出后检查：
- 机器人的关节可以用手轻松转动吗？（能 → 说明卸力正常）
- 电机有没有异常发热？
- 运行日志（如果有 `--log` 选项）里有没有奇怪的报错

---

## 可能的现象

| 你看到的 | 可能的原因 |
|---------|-----------|
| 机器人站起来，但**抖得很厉害** | 刚度/阻尼参数可能需要微调，正常的首次情况 |
| 机器人站起来后**站不稳，往一个方向倒** | 地面不平，或者模型还没训练够 |
| 机器人**走几步就自己停下来了**（回到 Passive） | 倾角太大触发了保护机制——这是好的 |
| 机器人**完全不按摇杆走** | 检查摇杆连接，或者切回 Passive 重启 |
| 机器人**走起来左右偏** | IMU 的角度可能有偏差，正常范围内 |
| 机器人**走得和仿真里不一样** | 正常的——真机和仿真永远有差距 |

---

## 安全守则（再说一遍）

1. **第一次一定要有人扶着**
2. **L2+B 是急停——刻在脑子里**
3. **机器人倒就让它倒，别用手接**
4. **远离墙壁、桌角、其他人的脚**
5. **听到异响（金属摩擦、电机啸叫）→ 立刻急停**
