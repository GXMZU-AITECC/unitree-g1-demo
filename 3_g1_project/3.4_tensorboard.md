# 用 TensorBoard 监控训练曲线

> 训练跑起来了，但命令行里只有数字。TensorBoard 能把训练曲线画成图，看着一目了然。
>
> 预计时间：~2 分钟

---

## 启动 TensorBoard

在另一个终端（不要关训练终端）运行：

```bash
tensorboard --logdir ~/projects/g1-rl/logs/rsl_rl/unitree_g1_29dof_velocity \
            --bind_all --port 6006
```

打开浏览器访问 `http://localhost:6006`。

如果报 `ModuleNotFoundError: No module named 'tensorboard'`：

```bash
pip install tensorboard
# 如果还报 pkg_resources 缺失：
pip install "setuptools<70"
```

## 核心指标看哪些？

默认进入的是 **Scalars（数值曲线）** 页面。右下角有滚动条可以翻。

### 最重要的 6 个指标

| 指标 | 名称 | 怎么看 | 好的趋势 |
|------|------|--------|----------|
| 🏆 每局平均奖励 | `rollout/ep_rew_mean` | 整条线往上走就是好的 | 📈 持续上升 |
| 🏃 每局平均步数 | `rollout/ep_len_mean` | 机器人能走更久 | 📈 上升到 400（走满） |
| 📐 价值网络损失 | `loss/value_loss` | 预测误差 | 📉 逐渐下降 |
| 🎯 PPO 替代损失 | `loss/surrogate_loss` | PPO 的核心损失 | 震荡但总体稳定即可 |
| 🌪️ 策略熵 | `loss/entropy_loss` | 探索程度 | 📉 缓慢下降（收敛） |
| 📚 学习率 | `info/learning_rate` | 自动调整的学习率 | 自适应下降 |

### Episode 相关指标（需要往下翻）

| 指标 | 含义 | 好的趋势 |
|------|------|----------|
| `Episode_Termination/bad_orientation` | 摔倒比例 | 从 1.0 降到接近 0 |
| `Episode_Termination/time_out` | 超时比例（走满 20 秒） | 从 0 逐渐上升 |
| `Episode_Reward/track_lin_vel_xy` | 速度跟踪得分 | 📈 持续增大 |

## 操作技巧

1. **横向拖动底部滑块** → 放大/缩小时间范围
2. **点击曲线上某个点** → 看精确数值
3. **左侧 Run 列表多选** → 对比不同训练轮次的表现
4. **勾选 "Show data download links"** → 导出 CSV 数据
5. **鼠标悬停在曲线上方** → 平滑 / 指数平滑 / 忽略异常点

## 典型训练曲线解读

### 一个健康的训练曲线长这样

```
           rollout/ep_rew_mean
  20 ┤                                ╭──────
  15 ┤                           ╭────╯
  10 ┤                      ╭────╯          ← 后期稳定在高位
   5 ┤                 ╭────╯
   0 ┤──────╮    ╭────╯                     ← 中间快速上升
  -5 ┤      ╰────╯                          ← 初期挣扎（负值）
      ├──────┼──────┼──────┼──────┤
      0    2000   4000   6000   8000  steps

  如果曲线不升反降 → 可能是学习率太大，或者奖励函数需要调整
  如果一直震荡 → 可能探索太多（entropy 过高）
  如果上升后又暴跌 → 可能 PPO 的 clip 范围内突变
```

## 常见问题

### TensorBoard 里看不到数据？

```bash
# 确认日志目录有 tfevents 文件
ls ~/projects/g1-rl/logs/rsl_rl/unitree_g1_29dof_velocity/*/events.out.tfevents*
# 如果有多个文件，确保 --logdir 指向了正确的父目录
```

### 远程服务器上跑训练，本机怎么看到 TensorBoard？

```bash
# 在远程服务器上：
tensorboard --logdir ... --bind_all --port 6006

# 在本机上（打开浏览器访问）：
http://<远程服务器IP>:6006
```

### 训练停了还能看之前的曲线吗？

能。TensorBoard 读的是日志文件，和训练是否在跑无关。随时都可以看历史曲线。
