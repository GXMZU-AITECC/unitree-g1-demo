# 配置指南 — 修改训练参数

> 你想改场地大小？调奖励权重？让机器人走快点？这章告诉你怎么改。
>
> 配置文件是 Python 代码（不是 YAML），长但很容易懂。

## Part 1：地形配置（第 46 行）

```python
COBBLESTONE_ROAD_CFG = terrain_gen.TerrainGeneratorCfg(
    size=(8.0, 8.0),          # 每块地形长×宽（米）
    border_width=20.0,         # 四周平坦边框宽度（米）
    num_rows=6,                # 地形行数（纵向）
    num_cols=6,                # 地形列数（横向）
    ...
)
```

**总场地大小计算**：
```
总宽度 = num_cols × size[1] + 2 × border_width
总长度 = num_rows × size[0] + 2 × border_width
```

当前默认参数：`6 × 8 + 2 × 20 = 88m × 88m` × 4 envs = 非常大的场地。

### 调小场地（看机器人更清楚）

```python
# 适合回放时用：2×2 小场地
self.scene.num_envs = 1
self.scene.terrain.terrain_generator.num_rows = 2
self.scene.terrain.terrain_generator.num_cols = 2
self.scene.terrain.terrain_generator.border_width = 5.0
self.scene.terrain.terrain_generator.size = (2.0, 2.0)
```

### 训练场 vs 回放场

文件末尾的 `RobotPlayEnvCfg` 类（约第 465 行）覆盖了回放时的场地配置，**和训练是分开的**。你可以让训练场很大、回放场很小。

## Part 2：训练参数（第 413 行附近）

```python
@configclass
class RobotEnvCfg:
    scene = Scene(num_envs=4096, ...)     # 并行环境数
    observations = ...                     # 观测空间
    actions = ...                          # 动作空间
    events = ...                           # 随机事件
    rewards = ...                          # 奖励函数
    terminations = ...                     # 终止条件
    curriculum = ...                       # 课程学习
    commands = ...                         # 速度指令
```

### 调并行环境数

通过环境变量 `TRAIN_NUM_ENVS` 修改（更简单）：

```bash
TRAIN_NUM_ENVS=64 bash scripts/start.sh train
```

也可以在配置里改：

```python
self.scene.num_envs = 128  # 默认 4096，实际由 --num_envs CLI 参数覆盖
```

### 调 Episode 长度

```python
# 每局最长 20 秒，超过就停止
self.episode_length_s = 20.0   # 改成 30 秒让机器人走更久
```

### 调仿真精度

```python
self.sim.dt = 0.005             # 物理步长，越小越精确但越慢
self.decimation = 4             # 策略每隔 4 个物理步做一次决策
# 实际策略频率 = 1 / (0.005 × 4) = 50Hz
```

## Part 3：奖励权重（最难也最重要）

奖励函数决定了机器人"学什么"。在 `velocity_env_cfg.py` 里搜索 `@configclass class RewardsCfg`。

```python
@configclass
class RewardsCfg:
    # 速度跟踪（正奖励 — 走得合指令就加分）
    track_lin_vel_xy_exp = RewTerm(func=track_lin_vel_xy_l2_kernel, weight=1.0, ...)
    #                ↑ 用指数核计算速度跟踪误差            ↑ weight 就是得分权重
    
    track_ang_vel_z_exp = RewTerm(func=track_ang_vel_z_l2_kernel, weight=0.5, ...)
    #                                                                         ↑ 0.5: 转角跟踪权重是线速的一半
    
    # 存活奖励（固定加分）
    alive = RewTerm(func=is_alive, weight=0.15, ...)
    
    # 各种惩罚（负权重 — 做了这些事就扣分）
    lin_vel_z_l2 = RewTerm(func=lin_vel_z_l2, weight=-2.0, ...)       # 身体上下晃动
    ang_vel_xy_l2 = RewTerm(func=ang_vel_xy_l2, weight=-0.05, ...)    # 身体侧倾/前倾
    dof_vel_l2 = RewTerm(func=dof_vel_l2, weight=-0.01, ...)          # 关节动太快
    dof_acc_l2 = RewTerm(func=dof_acc_l2, weight=-2.5e-7, ...)        # 关节加速度
    action_rate_l2 = RewTerm(func=action_rate_l2, weight=-0.01, ...)   # 动作变化太剧烈
    dof_pos_limits = RewTerm(func=dof_pos_limits, weight=-10.0, ...)  # 关节转到极限
    energy = RewTerm(func=joint_power, weight=-2e-5, ...)              # 省电
    undesired_contacts = RewTerm(func=undesired_contacts, weight=-1.0, ...) # 不该碰地的部位碰地
    flat_orientation_l2 = RewTerm(func=flat_orientation_l2, weight=-1.0, ...)# 身体要直
    base_height_l2 = RewTerm(func=base_height_l2, weight=-5.0, ...)   # 保持身高
```

### 怎么调

| 你想... | 怎么改 |
|----------|--------|
| 机器人走得更快 | 把 `track_lin_vel_xy_exp` 的 `weight` 从 `1.0` 调到 `2.0` |
| 机器人步态更平滑 | 把 `action_rate_l2` 的 `weight` 从 `-0.01` 调到 `-0.05`（更大力惩罚突变动作） |
| 机器人能走更久不摔 | 把 `flat_orientation_l2` 从 `-1.0` 调到 `-2.0` |
| 降低能耗 | 把 `energy` 的 `weight` 从 `-2e-5` 调到 `-5e-5` |
| 机器人站得更高 | 把 `base_height_l2` 从 `-5.0` 调到 `-8.0` |

> ⚠️ 权重调太大（比如把某个惩罚调到 `-100`）可能会导致机器人什么都不敢做、直接站着不动。

## 训练 vs 回放的配置分离

文件末尾：

```python
@configclass
class RobotEnvCfg:
    # ← 这是训练用的配置
    def __post_init__(self):
        self.scene.num_envs = 4096       # 训练用并行环境数
        self.terrain.terrain_generator = COBBLESTONE_ROAD_CFG

@configclass
class RobotPlayEnvCfg(RobotEnvCfg):
    # ← 继承训练配置，只覆盖需要改的
    def __post_init__(self):
        super().__post_init__()
        self.scene.num_envs = 4          # 回放只用 4 个环境
        self.scene.terrain.terrain_generator.num_rows = 6
        self.scene.terrain.terrain_generator.num_cols = 6
```

## 修改后怎么生效

配置文件是 Python 代码，改完保存就生效。不需要重新构建 Docker 镜像，不需要重新 `pip install`：

```bash
# 改完配置后直接重新训练
bash scripts/start.sh train
```

`scripts/start.sh` 已经把 `/sim/` 目录挂载到容器里了，容器内读到的是实时的修改。
