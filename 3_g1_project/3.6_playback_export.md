# 回放与模型导出 — 看机器人走路 + 部署到真机

> 你训练完了。现在要看机器人实际走得怎么样，然后把模型导出给真机部署。

---

## 回放：在 3D 画面中看机器人走路

```bash
bash scripts/start.sh play <run_folder> <checkpoint>
```

例如：

```bash
# 回放最终模型
bash scripts/start.sh play 2026-06-24_15-30-00 model_20000.pt

# 回放中间的 checkpoint（看训练到一半是什么水平）
bash scripts/start.sh play 2026-06-24_15-30-00 model_500.pt
```

`<run_folder>` 是 `logs/rsl_rl/unitree_g1_29dof_velocity/` 下的时间戳目录名。

回放启动后，Isaac Sim 的 3D 窗口会打开，显示 G1 机器人在你训好的模型控制下走路。

---

## 训练和回放的对应关系

```
训练（train）                       回放（play）
─────────────────────────────────────────────────────
不渲染 3D 画面                      ✅ 渲染完整的 3D 画面
4-4096 个机器人同时训练             只回放少量机器人（默认 32，可通过 PLAY_NUM_ENVS 调整）
GPU 满载计算                         GPU 轻载（大部分在渲染）
模型每 100 轮存一次                 你选哪个 checkpoint 就看哪个
```

## 导出模型（部署到真实 G1）

训好的模型是 PyTorch `.pt` 文件。真机部署需要 **ONNX 格式**：

```bash
# play 脚本会自动导出
bash scripts/start.sh play 2026-06-24_15-30-00 model_20000.pt
```

导出后，`logs/rsl_rl/unitree_g1_29dof_velocity/2026-06-24_15-30-00/exported/` 里会有：

```
exported/
├── model.jit          # TorchScript 格式（torch.jit.load 加载）
└── model.onnx         # ONNX 格式（ONNX Runtime 加载，真机用这个）
```

---

## 真机部署简介

Unitree 官方提供了 C++ 部署程序，使用 `model.onnx`。具体流程：

1. 把 `model.onnx` 拷贝到 G1 机器人的板载电脑
2. 运行官方的 `g1_ctrl` 程序：
   https://github.com/unitreerobotics/unitree_rl_lab/tree/main/deploy
3. 切换到 RL 控制模式，机器人开始按模型决策执行动作

> 真机部署涉及 ROS 2 通信和安全性（急停开关、力控模式切换），这超出了仿真教程的范畴。

## 常见问题

### 3D 窗口是黑的？

1. 确保 `start.sh` 里 docker run 带了 `--user 0:0`（本项目已配置）
2. 确保容器里有 `OMNI_KIT_ALLOW_ROOT=1` 环境变量
3. 确保 X11 转发正常：
   ```bash
   xhost +local:
   echo $DISPLAY   # 应该输出 :0 或 :1
   ```

### play 报错 `'PPO' object has no attribute 'policy'`？

这是 rsl-rl-lib 5.x 的 API 变更（`PPO.policy` 改名成 `.actor`）。上游并没有替我们改好，是本仓 `scripts/apply_sim_fixes.py` 改的——重新克隆过 `sim/`，它就被冲回原样了。一行修回来：

```bash
python3 scripts/apply_sim_fixes.py --sim-root <你的仓库>/sim
```

为什么非改不可、怎么判断改好了 → [上游兼容补丁](../docs/upstream-patches.md)。

### 回放时机器人走得很奇怪？

可能原因：
1. **环境和训练时不一样** — 检查回放时的 terrain 配置是否覆盖了训练配置
2. **checkpoint 训练不足** — 试试 `model_5000.pt` 或 `model_10000.pt`
3. **并行环境数不匹配** — 训练用了 64 envs，回放用 4
