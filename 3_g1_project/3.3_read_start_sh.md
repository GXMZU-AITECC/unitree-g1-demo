## 第 1 层：变量定义（行 1-25）

```bash
#!/bin/bash              # 行1: 用 bash 来跑这个脚本
set -euo pipefail        # 行5: 任何命令出错就立刻停（安全模式）

TRAIN_TASK="${TRAIN_TASK:-Unitree-G1-29dof-Velocity}"  # 行7: 训练什么任务
TRAIN_NUM_ENVS="${TRAIN_NUM_ENVS:-4}"                  # 行8: 并行环境数
TRAIN_MAX_ITER="${TRAIN_MAX_ITER:-20000}"              # 行9: 训练轮数
```

**`${VAR:-default}` 的设计意图**：你可以在命令行设置这些变量，不设就用默认值。

```bash
# 用默认值（4 环境，20000 轮）
bash scripts/start.sh train

# 覆盖（64 环境，只跑 5000 轮）
TRAIN_NUM_ENVS=64 TRAIN_MAX_ITER=5000 bash scripts/start.sh train
```

**为什么用环境变量而不是命令行参数？** 因为 `start.sh` 要把这些值传给 Docker 容器里的 `train.py`。环境变量能跨进程传递。

```bash
IMAGE="nvcr.io/nvidia/isaac-sim:5.1.0"            # 行11: 用什么 Docker 镜像
SIM_DIR="${HOME}/projects/g1-rl/sim"               # 行12: G1 代码在哪
CACHE_DIR="${HOME}/.cache/isaac-sim"               # 行13: Isaac Sim 缓存
LOG_DIR="${HOME}/projects/g1-rl/logs"               # 行14: 训练日志
PIP_PKGS_DIR="${CACHE_DIR}/pip_pkgs"                # 行15: pip 包持久化位置
PIP_MIRROR="https://pypi.tuna.tsinghua.edu.cn/simple" # 行16: 清华 pip 镜像（国内快）
```

`PIP_MIRROR` 用了清华的 PyPI 镜像——因为默认 `pypi.org` 在国内太慢了。

```bash
EXTRA_PYTHONPATH="/sim/IsaacLab/source/isaaclab:..." # 行19: 追加 Python 搜索路径
```

**`PYTHONPATH` 是什么？** Python 找模块时会搜一串目录。这行告诉 Python："除了 Isaac Sim 自带的路径外，也去这几个目录找"——这样 `import unitree_rl_lab` 才能找到 `/sim/unitree_rl_lab/source/unitree_rl_lab/` 下的代码。

```bash
RED='\033[0;31m' ... NC='\033[0m'                  # 行21: 终端颜色代码
mkdir -p "${CACHE_DIR}"/{kit,ov,pip,...}             # 行23: 创建所有缓存目录
```

## 第 2 层：Docker 命令模板（行 27-68）

```bash
DOCKER_BASE="docker run --rm --gpus all --user 0:0 \
  -e ACCEPT_EULA=Y ... \
  --shm-size=8g --network=host \
  -v ${CACHE_DIR}/kit:/isaac-sim/kit/cache:rw \
  ..."
```

逐项解释：

| 参数 | 为什么 |
|------|--------|
| `--rm` | 容器退出后自动删除。不删的话每次 run 都会留下一个 stopped 容器（`docker ps -a` 能看到） |
| `--gpus all` | 把所有 GPU 分给容器。没这个容器里 `nvidia-smi` 看不到显卡 |
| `--user 0:0` | **以 root 运行**。Isaac Sim 需要写 `/root/.cache/`，不以 root 跑 → 3D 视口黑屏 |
| `-e ACCEPT_EULA=Y` | 接受 Isaac Sim 的用户协议（不设的话启动会弹协议窗口卡住） |
| `-e OMNI_KIT_ALLOW_ROOT=1` | 告诉 Isaac Sim 的 Kit 引擎：以 root 运行是可以的 |
| `--shm-size=8g` | 共享内存 8GB。PyTorch DataLoader 多进程通信需要 |

### 8 个 `-v` 挂载项

```bash
-v ${CACHE_DIR}/kit:/isaac-sim/kit/cache:rw       # 着色器缓存（不挂载每次启动都要编译→很慢）
-v ${CACHE_DIR}/ov:/root/.cache/ov:rw              # OpenUSD 纹理缓存
-v ${CACHE_DIR}/pip:/root/.cache/pip:rw            # pip 下载缓存
-v ${CACHE_DIR}/glcache:/root/.cache/nvidia/GLCache:rw  # OpenGL 着色器缓存
-v ${CACHE_DIR}/computecache:/root/.nv/ComputeCache:rw  # CUDA compute cache
-v ${CACHE_DIR}/logs:/root/.nvidia-omniverse/logs:rw    # Omniverse 日志
-v ${CACHE_DIR}/data:/root/.local/share/ov/data:rw      # Omniverse 数据
-v ${PIP_PKGS_DIR}:/isaac-sim/pip_pkgs:rw          # pip 包持久化（install 只做一次）
-v ${SIM_DIR}:/sim:rw                               # G1 代码挂载
-v ${LOG_DIR}:/isaac-sim/logs:rw                    # 训练日志持久化
```

### `run_python` 和 `run_python_gui` 函数（行 54-68）

```bash
run_python() {
    ${DOCKER_BASE} \
        --entrypoint bash "${IMAGE}" \
        -c "${ENV_WRAPPER} && /isaac-sim/kit/python/bin/python3 $@" 2>&1
}
```

- `${DOCKER_BASE}` — 展开为前面定义的那一大串 `docker run` 参数
- `--entrypoint bash` — 容器启动后运行 bash（而不是 Isaac Sim 默认的启动程序）
- `-c "命令"` — 告诉 bash："执行这条命令，然后退出"
- `${ENV_WRAPPER}` — 先设好 Isaac Sim 的环境变量（`PYTHONPATH` 等）
- `&&` — 环境设完之后，执行后面的 Python 脚本
- `"$@"` — 把调用 `run_python` 时传入的参数原样传进来
- `2>&1` — 把 stderr 合并到 stdout（错误和正常输出混在一起显示）

`run_python_gui` 多了两样：

```bash
xhost +local: 2>/dev/null                           # 允许 Docker 容器连宿主机的 X11 显示器
-e "DISPLAY=${DISPLAY}"                             # 告诉容器："在哪个屏幕渲染"
-v /tmp/.X11-unix:/tmp/.X11-unix:rw                 # X11 socket 文件映射
-v "${HOME}/.Xauthority:/root/.Xauthority:ro"       # X11 认证
```

**X11 是什么？** Linux 的图形显示系统。要让 Isaac Sim 的 3D 窗口显示在你的屏幕上，需要把 Docker 容器连到宿主机的 X11 显示服务。

## 第 3 层：7 个功能函数（行 71-147）

### `install()` — 安装依赖

```bash
${DOCKER_BASE} --entrypoint bash "${IMAGE}" -c "
  ...  在容器内执行多条 shell 命令，包括：
  1. source /isaac-sim/setup_python_env.sh  → 激活 Isaac Sim 自带的 Python
  2. export PYTHONPATH=...                   → 加路径
  3. rm -rf pip_pkgs/isaaclab               → 清理旧版
  4. pip install --target /isaac-sim/pip_pkgs gymnasium rsl-rl-lib==5.0.1
  5. echo '...' > pip_pkgs/unitree_rl_lab.pth → 创建 .pth 文件，告诉 Python "这也算一个包"
"
```

**`--target /isaac-sim/pip_pkgs`** 是关键——包装在宿主机的持久化目录里（通过挂载），而不是容器内。这样容器删了重开，包还在。

**`.pth` 文件是什么？** Python 在 `site-packages` 里发现 `.pth` 文件时，会把文件里写的路径追加到 `sys.path`。这样 `import unitree_rl_lab` 就能找到 `/sim/unitree_rl_lab/source/unitree_rl_lab/`。

### `train()` — 无头训练

```bash
run_python "/sim/unitree_rl_lab/scripts/rsl_rl/train.py \
  --task ${TRAIN_TASK} --num_envs ${TRAIN_NUM_ENVS} \
  --max_iterations ${TRAIN_MAX_ITER} --headless"
```

**`--headless`** = 不渲染 3D 画面，纯计算。训练速度最快。

### `train_gui()` — 带 3D 的训练

和 train 唯一区别：调用 `run_python_gui`（加了 X11 转发），不加 `--headless`。

### `visualize()` — 打开 Isaac Sim 的 3D 编辑器

```bash
--entrypoint /isaac-sim/runapp.sh "${IMAGE}"
```

直接运行 Isaac Sim 的 GUI 程序，不跑 Python 训练脚本。

### `play()` — 回放模型

```bash
local run_dir="${1:-none}"       # local = 函数内部局部变量
local checkpoint="${2:-none}"    # "${1:-none}" = 第一个参数，没给就默认 "none"
run_python_gui ".../play.py --load_run ${run_dir} --checkpoint .../${run_dir}/${checkpoint}"
```

### `shell()` — 交互式容器

```bash
${DOCKER_BASE} -it --entrypoint bash "${IMAGE}"
```

`-it` = `-i`(interactive, 输入) + `-t`(TTY, 伪终端)。两者一起用才能"像正常终端一样交互"。

## 第 4 层：主入口（行 150-187）

```bash
case "${1:-menu}" in
    install|i)             install ;;
    train|t)               train ;;
    ...
esac
```

- **`${1:-menu}`**：取第一个命令行参数。没给参数时默认 `menu`。
- **`case ... in`**：匹配第一个参数，跳到对应函数。
- 空输入匹配 `menu|m|""` → 显示交互式菜单（行 157-182）。
- `*)` 兜底（行 184-186）— 不认识的参数 → 报 usage 提示。

## 你现在能理解为什么这样设计了

1. **变量全部可被环境变量覆盖** → 灵活调参
2. **复杂的 docker run 参数封装到一个字符串变量** → 7 个函数复用同一模板
3. **`run_python` + `run_python_gui` 两个包装函数** → 训练和 GUI 各用各的
4. **持久化 pip 包 + `.pth` 文件** → install 只做一次，不用每次重装
5. **case 分支主入口** → 一条命令 `bash scripts/start.sh train` 跑全部
