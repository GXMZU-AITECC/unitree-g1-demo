## 训练跑不起来

### `ModuleNotFoundError: No module named 'gymnasium'`

**原因**：Isaac Sim 容器不自带 RL 训练库。

**修复**：
```bash
bash scripts/start.sh install
```

### `AttributeError: 'RslRlMLPModelCfg' object has no attribute 'stochastic'`

**原因**：rsl-rl-lib 5.0.1 移除了 `stochastic` 字段，但 IsaacLab 兼容层还在读它。

**修复**（已在项目代码中应用，下面是告诉你为什么）：

编辑 `sim/IsaacLab/source/isaaclab_rl/isaaclab_rl/rsl_rl/utils.py` 约第 309 行：

```python
# 修改前
elif model_cfg.stochastic is True:

# 修改后
elif hasattr(model_cfg, "stochastic") and model_cfg.stochastic is True:
```

### 训练启动后 GPU 没动静

**正常**。前 10-30 秒在初始化（编译着色器、注册环境）。之后 GPU 才会满载。用 `watch -n 1 nvidia-smi` 监控。

## 回放跑不起来

### `'PPO' object has no attribute 'policy'` 或 `'actor_critic'`

**原因**：rsl-rl-lib 5.x 把 `policy` 改名为 `actor`，删除了 `actor_critic`。

**修复**（已在项目代码中应用。如果重新克隆了 unitree_rl_lab 的话需要重新改）：

编辑 `sim/unitree_rl_lab/scripts/rsl_rl/play.py`，把：
```python
runner.alg.policy       → runner.alg.actor
runner.alg.actor_critic → (删除引用)
```
然后改用 `runner.export_policy_to_jit()` 和 `runner.export_policy_to_onnx()` 导出模型。

### Isaac Sim GUI 窗口是黑的

**原因**：容器用户没有写入缓存的权限。Isaac Sim 需要写 shader cache、ogn cache 等。

**修复**：`docker run` 时加 `--user 0:0`：
```bash
docker run --rm --gpus all --user 0:0 ...
```
本项目 `scripts/start.sh` 已经配置好了（第 27 行：`--user 0:0`）。

### play 跑到一半崩溃在 export

**原因**：`get_inference_policy()` 返回的策略对象格式和手动 export 不兼容。

**修复**：已在 `play.py` 中改为用 `runner.export_policy_to_jit()` 和 `runner.export_policy_to_onnx()`—— rsl-rl-lib 5.x 内置方法。

## 显卡相关

### nvidia-smi 报"No devices were found"

```bash
# 检查驱动
ubuntu-drivers devices
# 重装驱动
sudo apt install -y nvidia-driver-580-open
sudo reboot
```

### docker --gpus all 报"could not select device driver"

```bash
dpkg -l nvidia-container-toolkit          # 确认已装
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

### 训练时显存不够

减少并行环境数：
```bash
TRAIN_NUM_ENVS=2 bash scripts/start.sh train
```

或者在 `velocity_env_cfg.py` 里减小网络尺寸：
```python
# 当前：[512, 256, 128]
# 省显存：[256, 128, 64]
actor_hidden_dims=[256, 128, 64]
critic_hidden_dims=[256, 128, 64]
```

## Docker 相关

### permission denied while trying to connect to the docker API

```bash
sudo usermod -aG docker $USER
# 注销重新登录，或者临时用 newgrp docker
```

### Isaac Sim 在容器里 segfault

**原因**：驱动版本不对。Isaac Sim 5.1.0 需要驱动 580.x。

```bash
nvidia-smi | head -3   # 看当前版本
# 如果是 595.x → sudo apt install nvidia-driver-580-open && sudo reboot
```
